PACKET_ANALYSIS = """
## 📡 抓包分析指南

### 为什么需要抓包？
优化代码中的视频URL提取逻辑基于常见模式。
如果播放失败，可能是因为：
1. 网站使用了特殊的加密方式
2. 视频URL在JavaScript中动态生成
3. 使用了第三方播放器

### 如何抓包？

#### 方法1: Chrome开发者工具
1. 打开目标播放页
2. 按F12打开开发者工具
3. 切换到Network标签
4. 点击播放按钮
5. 查找m3u8、mp4或player相关请求
6. 查看Response中的URL

#### 方法2: Fiddler
1. 配置代理
2. 开启HTTPS捕获
3. 播放视频
4. 查找视频流请求

#### 方法3: Charles
1. 配置代理和SSL
2. 录制请求
3. 播放视频
4. 分析请求和响应

### 常见的视频URL格式

#### 格式1: M3U8（HLS流）
```
https://cdn.example.com/video.m3u8?token=xxx
```
特征：
- 文件扩展名是.m3u8
- 包含#EXTM3U头
- 包含多个.ts分片

#### 格式2: MP4（直接视频）
```
https://cdn.example.com/video.mp4?key=xxx
```
特征：
- 文件扩展名是.mp4
- 可以直接下载或播放

#### 格式3: iframe嵌套
```html
<iframe src="https://player.example.com/embed/xxx">
```
特征：
- 播放源在其他域名
- 需要二次解析

### 如何根据抓包结果优化代码？

1. 复制m3u8或mp4的完整URL
2. 分析URL的生成规律
3. 在代码中添加相应的正则表达式
4. 重新测试播放

示例：
```python
# 如果发现URL是这样的格式：
# https://player.example.com/play?id=xxx&token=yyy

# 可以添加这样的提取逻辑：
pattern = r'player\.example\.com/play\?id=(\d+)&token=(\w+)'
matches = re.search(pattern, html)
if matches:
    video_url = f"https://player.example.com/play?id={matches.group(1)}&token={matches.group(2)}"
```

### 高级技巧

#### 技巧1: 分析JavaScript
如果URL在JS中生成：
1. 在Network中查找JS文件
2. 搜索关键词：video、player、url、src
3. 分析JS逻辑
4. 在Python中实现相同逻辑

#### 技巧2: 使用Selenium
如果JS逻辑太复杂：
```python
from selenium import webdriver

driver = webdriver.Chrome()
driver.get(play_url)

# 等待视频加载
time.sleep(5)

# 获取视频元素
video = driver.find_element_by_tag_name('video')
video_url = video.get_attribute('src')

driver.quit()
```

#### 技巧3: 分析加密参数
如果URL包含加密参数：
1. 分析加密算法
2. 在Python中实现解密
3. 构造完整的播放URL
"""
